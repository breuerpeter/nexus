# Security policy

## Supported versions

nexus is pre-1.0 and under active development. Security fixes go to
the newest release on PyPI and the `main` branch only.

## Reporting a vulnerability

Please **don't** open a public GitHub issue for security vulnerabilities.

Instead, report privately via GitHub's
[**Report a vulnerability**](https://github.com/breuerpeter/nexus/security/advisories/new)
workflow, under Security → Advisories. This opens a private advisory visible only to
the maintainers.

When reporting, please include:

- A description of the vulnerability and its impact
- Steps to reproduce, or a proof of concept
- Affected versions and the environment, with the OS, Python, GPU, and driver

The maintainers acknowledge each report and keep you informed of the fix and disclosure
timeline. Please give them a reasonable opportunity to address the issue
before any public disclosure.
