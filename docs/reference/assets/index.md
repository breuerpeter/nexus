# Assets

The named assets nexus loads at launch, both resolved from the registry
at `nexus/_src/config/registry.yaml`: the **vehicles** it flies and the **scenes**
it flies them in.

<div class="grid cards" markdown>

-   **[Vehicles](vehicles.md)**: the supported airframes and their models, selected with `--vehicle`.
-   **[Scenes](scenes.md)**: the static worlds the vehicle flies in, selected with `--scene`.

</div>

The hosted asset files are downloadable and usable with nexus but not
redistributable. See [the license page](../../license.md#hosted-assets).
